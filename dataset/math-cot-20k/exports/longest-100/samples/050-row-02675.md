We must ensure that the equation $ x = y^2 - y + a $ has **no other solutions** besides the ones where $ y = x $. In other words, we must ensure that the equation:

$$
x = y^2 - y + a \quad \text{with} \quad y \ne x
$$

has **no real solutions**.

Let’s consider the equation:

$$
x = y^2 - y + a \Rightarrow y^2 - y + (a - x) = 0
$$

This is a quadratic in $ y $, and for it to have **no real solutions** other than those with $ y = x $, we must ensure that **for all real $ x $**, this equation has at most one solution and that solution is $ y = x $.

But more practically, we can consider the **composition** of functions to analyze all real solutions to the system.

Let $ y = x^2 - x + a $, and substitute into $ y_1 = y^2 - y + a $:

$$
y_1 = (x^2 - x + a)^2 - (x^2 - x + a) + a
$$

Set $ y_1 = x $, and we get:

$$
(x^2 - x + a)^2 - (x^2 - x + a) + a = x
$$

Let’s denote $ z = x^2 - x + a $, then the equation becomes:

$$
z^2 - z + a = x
$$

This is a quartic equation in $ x $, and solving it gives **all** $ x $-values where $ y_1 = x $. We want to ensure that **only** the roots of $ x^2 - 2x + a = 0 $ are solutions to this quartic.

Let’s factor the quartic. Expanding and simplifying the equation:

$$
(x^2 - x + a)^2 - (x^2 - x + a) + a = x
$$

This simplifies to:

$$
x^4 - 2x^3 + 2a x^2 - 2a x + a^2 = x
$$

Bring all terms to one side:

$$
x^4 - 2x^3 + 2a x^2 - (2a + 1)x + a^2 = 0
$$

This quartic factors as:

$$
(x^2 - 2x + a)(x^2 + a) = 0
$$

So the solutions are:

- From $ x^2 - 2x + a = 0 $: the two points $ A $ and $ B $
- From $ x^2 + a = 0 $: solutions $ x = \pm \sqrt{-a} $

To ensure **no other real solutions**, the second factor must have **no real roots**. That is, we require:

$$
x^2 + a = 0 \quad \text{has no real solutions} \Rightarrow a > 0
$$

If $ a = 0 $, then $ x^2 + a = 0 $ becomes $ x^2 = 0 $, which has a **double root** at $ x = 0 $. But this is already a solution to $ x^2 - 2x = 0 $, so it does **not** introduce a new point. Thus, $ a = 0 $ is still acceptable.

- The function $ y_1 = y^2 - y + a $ intersects $ y_1 = x $ **only at those two points** if and only if $ a \ge 0 $
