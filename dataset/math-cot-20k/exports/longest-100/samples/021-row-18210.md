### Understanding the Tournament Structure

In a round-robin tournament with $ n $ players:
- Each player plays $ n-1 $ matches.
- There are no ties, so each match results in one win and one loss.
- The number of total games is $ \binom{n}{2} $, and each game contributes one point (to the winner).

For any subset of four players, we can examine the **induced subgraph** of the tournament (i.e., the matches between only those four players). The point total for a player in this subset is the number of wins they have **among just these four players**.

The condition in the problem is equivalent to saying that **every induced subgraph on four vertices must not have all four distinct out-degrees**. In other words, **there must not exist a four-player subset where the scores (number of wins among themselves) are all different**.

---

### Reformulating the Problem

This is equivalent to saying that the tournament must not contain a **transitive subtournament on four vertices**. In a transitive tournament of four players, the scores are all distinct: one player has 3 wins, one has 2, one has 1, and one has 0. Therefore, if we can avoid such a structure in all four-player subsets, the condition is satisfied.

Hence, the problem becomes:

> What is the **maximum number of players $ n $** such that there exists a tournament on $ n $ players **with no four-player transitive subtournament**?

This is a known problem in **tournament Ramsey theory**. Specifically, the **Ramsey number for transitive tournaments**, $ R(4) $, is defined as the smallest $ n $ such that **every tournament on $ n $ vertices** contains a **transitive subtournament of size 4**.

It is a known result that:
- $ R(4) = 8 $
- Therefore, the **maximum number of players** for which it is possible to construct a tournament with **no four-player transitive subtournament** is $ n = 7 $.

---

### Constructing a Valid Tournament

A well-known construction that achieves this is the **Paley tournament**, defined for prime powers $ q \equiv 3 \mod 4 $. The Paley tournament on 7 vertices (since 7 is a prime $ \equiv 3 \mod 4 $) is a **regular**, **strongly connected** tournament where each player has 3 wins and 3 losses.

This tournament is **symmetric and highly structured**, and it is known to **contain no four-player transitive subtournament**. This satisfies the condition of the problem.

$$
