f(c + h) = f(c - h) \quad \text{for all } h.

In this case, we set $ c = -\frac{\pi}{8} $, so the symmetry condition becomes:

f\left(-\frac{\pi}{8} + h\right) = f\left(-\frac{\pi}{8} - h\right).
