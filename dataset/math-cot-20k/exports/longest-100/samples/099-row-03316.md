To solve the problem, we begin by understanding the behavior of the function $ S(n) $, defined as:

$$
S(n) = \left\lfloor \frac{n}{10^{\lfloor \log_{10} n \rfloor}} \right\rfloor + 10 \left(n - 10^{\lfloor \log_{10} n \rfloor} \left\lfloor \frac{n}{10^{\lfloor \log_{10} n \rfloor}} \right\rfloor \right)
$$

This function essentially moves the **first digit** of the number $ n $ to the **end**, treating $ n $ as a decimal number. For example, if $ n = 1234 $, then $ S(n) = 2341 $.

We are interested in the condition:

$$
S(S(n)) = n
$$

This implies that applying the function $ S $ twice returns the original number. In other words, $ S $ is an **involution** at these numbers.

---

### Step-by-Step Analysis:

#### **1. Single-digit numbers (1 to 9)**

- For any $ n $ with a single digit, $ S(n) = n $, so $ S(S(n)) = n $.
- **Count**: 9 numbers

#### **2. Two-digit numbers (10 to 99)**

- If $ n = 10a + b $, then $ S(n) = 10b + a $, and $ S(S(n)) = 10a + b = n $.
- So $ S(S(n)) = n $ always holds **unless** $ b = 0 $, in which case $ S(n) $ becomes a single-digit number, and $ S(S(n)) \ne n $.
- **Invalid numbers**: 10, 20, ..., 90 (9 numbers)
- **Valid numbers**: $ 90 - 9 = 81 $
- **Count**: 81 numbers

#### **3. Three-digit numbers (100 to 999)**

- $ S(n) $ rotates the first digit to the end, and $ S(S(n)) $ rotates it twice.
- For $ S(S(n)) = n $, the number must be **invariant under two digit rotations**.
- This only occurs when **all digits are equal**, e.g., 111, 222, ..., 999.
- **Count**: 9 numbers

#### **4. Four-digit numbers (1000 to 4999)**

- For $ S(S(n)) = n $, the number must be of the form $ abab $ (where $ a \ne 0 $ and $ b \ne 0 $), or all digits equal.
